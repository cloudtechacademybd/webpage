# webpage

A single-page website for a bookkeeping service: services, process, regions served and a contact section.

- `index.html` — home page
- `services.html` — detailed page for each service (what's included, what we need, what you receive)
- `styles.css` — shared styles for all pages (light and dark mode, mobile layout)

No build step: plain HTML and CSS.

## Editing

- **Business name:** search for `Clear Ledger` in every `.html` file and replace it.
- **Contact email:** replace `hello@example.com`.
- **Colours:** change the `--accent` values at the top of `styles.css`.

## Publishing with GitHub Pages

GitHub Pages on a free account needs the repository to be public. Then go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save. The site will appear at `https://cloudtechacademybd.github.io/webpage/`.
